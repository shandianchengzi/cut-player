# Cut Player v1.5.27

- Windows 打开的所有视频自动开始排队分析音频波形与帧时间轴，包括多选、拖入、打开方式和重启恢复的后台标签，不再依赖切到前台。
- 每个文件使用独立读取通道；切换 / 关闭标签不再中断已开始的分析，完成后写入本机缓存。重复请求同一文件共用正在运行的任务。
- 按资源情况同时分析 1–2 个视频，其余依次处理；界面只保留有限数量的完整分析数组，切回其他已完成视频时读取缓存。
- 波形进度与结果按文件和请求归属更新，后台任务不会覆盖当前视频的波形、文字、播放状态或导出源。
- 增加队列并发 / 去重 / 取消测试，以及从未激活的视频也生成真实音频波形和帧缓存的 Windows 桌面回归检查。
