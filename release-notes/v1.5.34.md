# Cut Player v1.5.34

- 将「精细切割（逐帧）」改为「无损关键帧」，界面不再承诺与流复制不相容的任意帧精切。
- FFprobe 分析只保留关键帧时间；方向键在相邻关键帧间移动，波形点击吸附最近关键帧，记录使用同一时间轴。
- 无损关键帧模式导出前在界面和主进程双重校验断点，手工修改或旧记录中的非关键帧会被拒绝。
- 合并在无损关键帧模式下复核 H.264 / H.265 随机访问边界；开放 GOP 等不能独立解码的边界直接报错，不再静默扩大选区。
- 视频及音频继续使用 `-c copy` 原码流复制，不重新编码；普通模式保持原有向安全边界扩展的兼容行为。
- 更新单元与 Electron 真实媒体回归，覆盖关键帧导航、无损切割、AAC 提取、长 GOP、B 帧及 H.264 / H.265 开放和闭合 GOP 合并。
