# Cut Player v1.5.22

- 精细切割自动名称由 13 位 Unix 时间戳改为连续 17 位日期时间：yyyyMMddHHmmssSSS。例：DJI_20261017191600123x歌名.mp4。
- 日历源文件保留原钟面时间；旧 Unix 源文件按 UTC+8 显示，毫秒补零并正确处理跨日进位。
- 普通模式及已有手动名称保持不变。

## Android 首个测试 APK

- Android 8.0+，提供 arm64-v8a 手机包和 x86_64 模拟器包，内置 FFmpeg / FFprobe 6.1.1。
- 本地视频多选、独立标签和两行时间记录；前台服务固定导出源，期间可打开下一个视频。
- 视频及音轨均采用 `-c copy`；显示导出大小和实际总时长，支持停止、同名确认和源文件覆盖保护。无损切点仍受关键帧限制。
- 修正测试参考输出的硬编码结束时间，使用容器实际时长，逐包核对 MP4 / MKV、多音轨和独立音频的哈希及时间戳；取消、源覆盖保护和启动界面检查也纳入发布门槛。
- 首版使用测试签名，暂无桌面波形 / 逐帧界面和差分自动更新；正式签名更换时可能需要卸载，请先复制重要记录。
- Android FFmpeg 为独立 LGPL 2.1+ 组件，未启用 GPL / nonfree；对应源码、构建脚本和配置随 APK 一同发布。

详见 [Android 使用说明](https://github.com/shandianchengzi/cut-player/blob/main/android/README.md)。
