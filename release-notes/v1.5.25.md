# Cut Player v1.5.25

- 新增「批量切割 / 队列」入口：一次导入多个视频，查看名称、时长和对应配置行号。
- 同一个带行号的文本框批量填写，每两行 breakpoints / names 对应一个视频；可整段粘贴。
- 校验超出时长、名称数量、时间顺序等问题，点击错误定位对应行；有错误时禁止入队。
- 一键入队，自动根据 CPU 和可用内存调整并发；切割期间可关闭面板、继续操作和追加任务，无需手动配置。
- 独立任务进度、失败信息和停止按钮；冲突文件名禁止覆盖，配置入队后独立保存。
- 继续发布 NSIS 安装包及 blockmap，保留差分下载优先和完整包断点续传回退；发布前验证真实安装包差分重建。
