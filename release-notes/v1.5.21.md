# v1.5.21

- 新增 Android 原生首版测试 APK（Android 8.0+，arm64 手机；另附 x86_64 测试包）。
- 本地视频多选、标签页、播放 / 定位、记录 / 粘贴电脑端两行时间表、初始化与复制。
- 内置 FFmpeg / FFprobe 6.1.1，所有导出均 -c copy，不重编码；切点受关键帧限制，不承诺任意帧精确。保留视频容器和全部音视频轨道，独立音频提取第一音轨。
- 使用 Android 系统文件选择器授权文件和输出子目录，通过 fd: 随机读写直接导出，不先复制完整大视频到缓存；同名确认、源文件覆盖保护、停止保留部分结果、大小 / 时长对比。
- 导出固定视频和记录快照，前台服务允许切到其他应用继续运行；通知可停止。
- 模拟器测试比较与桌面参考导出的每个媒体包哈希和时间戳，包含 MP4 / MKV、双音轨、B 帧、毫秒切点、无音轨、源覆盖保护和取消。
- Android 是测试签名首版，尚无 Windows 波形 / 逐帧界面、快捷键及差分自动更新。未来更换正式签名可能需卸载，重要记录请先复制备份。
- Android FFmpeg 独立 LGPL 2.1+ 许可，未启用 GPL / nonfree；同一 Release 提供对应源码和构建配置。Windows 功能保持。

详见 [Android 使用与构建说明](../android/README.md)。
