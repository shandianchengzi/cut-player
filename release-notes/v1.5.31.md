# Cut Player v1.5.31

- 批量切割面板新增「仅导出原始音频（原名）」按钮：每个视频完整提取第一条原始音轨，不按切点拆分，不生成视频，保持 -c copy 无重编码。
- 保留视频原文件名，仅更换音频扩展名：AAC 为 .aac，其他音轨为 .mka。已有同名文件不会覆盖。
- 无需填写 breakpoints / names，不受分段音频复选框影响；导出后保留视频列表与编辑草稿。
- 复用原队列的自动并发、关闭面板后执行、逐项停止和结果显示。没有音轨的视频单独显示失败，其他任务继续。
- 增加 AAC / Opus 完整时长和音频包一致性、无视频输出、无音轨隔离及同名保护的桌面与安装后测试。
- 保持原有切割 / 合并功能与差分更新。
