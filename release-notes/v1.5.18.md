# v1.5.18

- 启用 NSIS 原生差分下载，复用本机旧安装包缓存，只下载变化块；重建后执行 SHA-512 校验。
- 缺少旧缓存、blockmap 不可用、网络或重建校验失败时自动回退完整安装包，保留原有断点续传、重试及备用源。
- 显示差分所需下载量和完整下载回退状态，详情记录 updates.log。
- 备用下载站同时发布当前和最近两个版本的 blockmap；更早版本或无缓存仍可完整升级。
- 五种原生更新器集成测试覆盖正常差分、缺缓存、Range 请求失败、差分数据损坏及完整包损坏；构建时另外核对 v1.5.17 → 当前真实安装包的差分重建 SHA-512。
- v1.5.17 及以前客户端关闭差分，因此升级到本版仍使用完整下载。本版安装后，后续更新优先差分；节省量取决于版本变化和本机缓存。

- 导出状态区分 FFmpeg 尚未退出与写入完成后的时长核对阶段，30 秒无推进提示不再直接推断磁盘 / 定位故障；日志增加每次 FFmpeg / FFprobe 耗时。这改善诊断显示，并不保证消除尚未定位的导出等待。
