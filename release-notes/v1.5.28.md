# Cut Player v1.5.28

- Windows 新增「合并片段」按钮及跨标签片段选择、顺序调整和输出命名面板。
- 默认名称为「【合并】第一个已选片段的名称」；手动改名后不会因调整顺序而覆盖输入。
- concat inpoint / outpoint 直接从原视频流复制输出，不生成中间视频；同源相邻区间自动合并读取。
- 合并前检查轨道与编码参数，保护原片并检查输出冲突；支持停止与后台固定快照，完成后核对实际时长。
- 无重编码不保证任意切点逐帧精确，界面说明关键帧及接缝限制；不兼容时明确报错，不自动转码。
- 新增真实媒体包哈希 / 时间戳对比和跨标签 UI 回归；沿用差分更新及完整包回退。
