# v1.5.19

- 支持一次选择 / 拖入多个视频，每个文件一个标签页；Windows 启动参数和已有窗口的打开方式也支持多文件。
- 重复打开同一路径会切回已有标签，不重置记录。切换保留各自记录、播放位置、倍速、文本选区和波形缩放，切换后暂停播放。
- 标签可关闭，记录按视频路径暂存；重新打开同一路径恢复记录，重启恢复未关闭的标签和最后活动标签。移动 / 改名后的路径视为新文件。
- 旧版未关联文件的暂存文本保留为「未关联记录」标签，可复制备份。
- 仅保留一个视频播放实例，至多保留当前和两个非活动标签的分析缓存，其余按需从磁盘缓存恢复。
- 切割只处理当前标签。导出中禁用打开 / 切换 / 关闭，Windows 外部打开的新视频在切割结束后作为标签打开。
- 新增真实桌面测试覆盖多选、拖入、冷 / 热启动、多文件、记录 / 位置 / 倍速 / 选区隔离、重启 / 关闭恢复，以及不同标签的实际导出源。
- 保留流式读取与 Windows 源文件删除、无重编码、音频提取、总大小 / 时长核对及差分更新。
