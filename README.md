# Cut Player

Windows 视频时间记录小工具：[介绍与下载](https://shandianchengzi.github.io/cut-player/) · [Release](https://github.com/shandianchengzi/cut-player/releases/latest)

## 功能

- 左侧本地视频播放器和原生进度条，右侧可编辑时间记录，采用 `breakpoints` 和 `names` 两行结构。
- 按钮或 `Ctrl+Alt+V` 追加当前 `MM:SS` 断点及对应片段名称；按钮或 `Ctrl+Alt+C` 复制全部文本。
- ↑/↓ 调节音量，←/→ 快退/快进，默认 5% / 1 秒。
- 1/2/3/4 对应 1/2/4/16 倍速，可配置为 0.25—16。
- 上述十一个快捷键均可自定义，冲突校验，设置和记录在本机持久保存。
- 编辑记录时方向键与数字保留文本编辑功能，记录和复制组合键仍有效。快捷键为窗口内快捷键。
- 切换视频会询问是否重置记录；可按文本断点直接导出片段视频及音频。

## 下载与运行

支持 Windows 10/11 x64。Release 包含 nsis 安装版和 portable 免安装版。内置 Electron 运行时，无需打开或安装独立浏览器，无需联网播放本地文件。构建未进行代码签名。

支持 Chromium 可解码的 H.264/AAC MP4、WebM 等。MKV/MOV 是否可播放取决于实际编码；不包含通用 FFmpeg 软解码。极高倍速的音频表现取决于 Chromium。

## 上游代码评估

评估了 [wangrongding/tiny-player](https://github.com/wangrongding/tiny-player) 的 `packages/core/src/index.ts`、事件系统、控制器和 README。其核心基于 HTMLVideoElement，技术上可由 Electron 封装成桌面应用；包元数据标记 MIT，上游根目录无独立 LICENSE 文件。软解码在 README 中仍标记 WIP，不是现成的通用桌面解码器。

本项目围绕本地视频与时间记录需求独立实现同类 HTMLVideoElement 播放方案，未复制上游源码或发布其包，避免引入本任务无需的 HLS、模板及构建依赖。不是 tiny-player 原版的二进制打包。

## 片段名称与拍摄时间

```text
breakpoints:00:10,01:23
names:video_20260926_202424x,video_20260926_202434x,video_20260926_202547x
```

打开视频后断点为空，names 包含去扩展名后的原名称加 x。每次记录同时追加一个断点和一个名称，names 始终比断点多一个。自动名称以原视频拍摄时间加当前绝对播放位置计算，不累加上一个片段的时间。

支持 `video_YYYYMMDD_HHMMSS`、`DJI_YYYYMMDDHHMMSS_编号_D`、13 位 Unix 毫秒时间戳、11 位 Unix 秒时间戳（含前导零）。保留其他前后缀，仅替换时间部分；DJI 特殊归一化为 `DJI_YYYYMMDDHHMMSSx`。日历时间按文件名原始钟面时间计算，不进行时区转换，自动处理跨日、跨月、跨年。断点按秒向下取整，超过一小时使用累积分钟，例如 `60:10`。

未识别到拍摄时间的名称采用原名称加相对时间后缀；手工修改已有片段名称会保留。新增时校验两行结构、数量关系、断点格式和严格递增顺序，错误时提示且不改写文本。

## 内置 FFmpeg 无损分段

点击「切割」，选择输出目录；程序直接写入所选文件夹，以 names 中的名称导出每一段。范围依次为 0→第一个断点、相邻断点之间、最后断点→视频末尾。未设置断点时导出整段。源文件不改动；遇到同名输出文件会询问是否覆盖。

FFmpeg 6.1.1 Windows x64 随程序内嵌，不需要单独安装，不打开控制台窗口。视频保持原文件容器，映射所有视频和音轨。所有导出使用 `-c copy`，无解码重编码；切点受关键帧限制，不能保证帧级精确。

```sh
ffmpeg -hide_banner -nostdin -y -i input.mp4 -ss START -to END -map 0:v? -map 0:a? -c copy output.mp4
ffmpeg -hide_banner -nostdin -y -i output.mp4 -map 0:a:0 -c copy -vn output.aac
```

「同时导出无损音频」默认勾选。提取每段的第一条音轨：AAC 输出 .aac，其他编码输出 .mka，均原码流复制；无音轨时跳过并提示。失败会显示 FFmpeg 错误及已输出文件的目录。导出时窗口内显示片段进度，不运行 shell。

## 配置文件

快捷键、倍速、快进步长、音量步长和音频勾选状态，保存至 Electron userData 下的 `config.json`（Windows 通常为 `%APPDATA%/cut-player/config.json`）。采用临时文件加重命名保存；升级/重启自动读取。旧版浏览器存储设置首次运行自动迁移。文本记录仍自动暂存在本机。

FFmpeg 的 GPL 许可证、对应源码及构建信息见随包第三方声明；应用代码许可证不变。CI 同时测试源码运行和打包后的桌面 EXE，包括实际 MP4 分段、AAC 提取、关闭音频导出及配置文件落盘。

## 暂停与快速命名

空格默认切换播放/暂停，可在「快捷键与倍速」修改；快进/快退默认 1 秒，同一设置页可配置步长（0.1—600 秒）。编辑文本或导入名称时，空格仍输入普通空格，避免打字误触播放器。旧版配置自动增加暂停快捷键，保留原有设置。

右侧上半部分为切割文本，下半部分为可选名称按钮。点击「导入名称」，可粘贴内容或打开 UTF-8 .txt/.csv 文件，选择空格/换行、英文逗号或自定义字面分隔符；导入会替换原列表、去除空项与重复名称。逗号分隔可保留名称内部空格。

将光标放在文本框需要插入的位置，再点击名称按钮，即可直接粘贴名称；不替换或删除已有内容，包括已选中的文本。名称列表也保存在 config.json，重启无需重新导入。

## 音量波形与精细模式

视频下方显示随时间变化的音量波形（不是频率频谱），同步播放游标和已记录断点。打开视频后，内嵌 FFmpeg 流式分析音频峰值、内嵌 FFprobe 读取压缩包 PTS 并排序（常见 H.264/H.265/VP8/VP9 视频），不再逐帧解码整段视频。音量波形独立显示，结果按文件大小与修改时间缓存；再次打开无需重新分析。异常封装或一个包含多帧的编码，包时间不保证覆盖每个画面帧。无音轨时显示提示。

勾选「精细切割（逐帧）」后，原有快进/快退快捷键改为上一帧/下一帧并暂停，使用真实帧时间戳，适用于变帧率视频；其他快捷键不变。鼠标置于波形上：滚轮向上围绕当前游标放大，向下缩小，视频与波形共享同一时间范围；点击波形可定位，精细模式吸附到帧。

精细断点为 `MM:SS.mmm`。自动生成的名称将原日期时间或 Unix 秒时间替换为 Unix 毫秒时间，保留前后缀与 x；例如 `video_1790425464000x`。日历文件名按北京时间（UTC+8）转换，DJI 仍去掉尾部编号。开启时已有整秒断点升级为 `.000`、已有自动名称一并转换，手工替换的名称保留。精细模式设置也写入 config.json。

毫秒是帧时间的文本表示，29.97 等帧率会舍入到最近毫秒。现有 `-c copy` 导出策略保留，毫秒标记不等于保证帧级准确的视频切口；要保证任意画面帧精确切口需重编码，本工具不会偷偷切换编码方式。音频分析过程会临时解码为低采样率波形，但所有导出的媒体仍使用原码流复制。

开发环境在 Windows 运行前，需将匹配的 FFprobe 放到 `node_modules/ffmpeg-static/ffprobe.exe`；CI 自动下载并随安装包内嵌，终端用户无需下载或安装。

## v1.4.1 交互修正

支持拖拽本地视频到窗口打开，沿用切换视频前的记录重置确认。可选名称仅在光标处插入，不再提供「替换片段」。按钮简化为「复制」「切割」。导出直接保存到所选目录，不创建额外子目录；同名文件在覆盖前询问，源视频同名则阻止导出。

播放器快捷键在捕获阶段处理，阻止 Chromium 原生视频快捷键叠加；单次左右键精确移动配置的秒数，默认 1 秒，长按自动重复不追加跳转。精细模式仍为逐帧。Windows 桌面测试覆盖视频获得焦点时的左右键和实际拖放导入。

## v1.4.2 播放焦点与按键释放

播放/暂停控件改为应用自有按钮，不进入 Tab 焦点序列；点击时保留或恢复视频焦点。进度条与音量滑块保留。播放/暂停快捷键只在松开时切换，按下和长按不切换，防止按下暂停、松开又播放。自定义播放/暂停键同样在释放时生效；失去窗口焦点后清除待释放状态。

默认快进/快退改为 1 秒，恢复默认也使用 1 秒。旧版默认 5 秒自动迁移为 1 秒，其他已保存步长保留，可在设置中修改。

## v1.5.0 更新与轻量分析
