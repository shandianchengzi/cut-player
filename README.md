# Cut Player

Windows 本地视频时间记录与无损分段工具。当前发布版本：**v1.5.11**。

[介绍与使用方法](https://shandianchengzi.github.io/cut-player/) · [下载最新版](https://github.com/shandianchengzi/cut-player/releases/latest) · [备用下载](https://shandianchengzi.github.io/cut-player/updates/) · [版本记录](CHANGELOG.md)

## 能做什么

- 打开或拖入本地视频，也支持 Windows「打开方式」传入视频；程序已运行时在原窗口接收新文件。
- 自定义进度、音量和全屏控制；长按左右键连续快退 / 快进。点击音量波形定位时保持原来的播放 / 暂停状态。
- 记录当前时间，生成可编辑的 `breakpoints` / `names` 两行文本，按文件名中的拍摄时间生成片段名称。
- 精细模式支持逐帧定位、毫秒断点与名称；滚轮缩放波形。**导出仍为原码流复制，切点受关键帧限制，不能保证逐帧精确。**
- 滚动选择并删除片段记录，或确认后初始化记录以恢复两行结构。
- 内置按此前整理的周深北京鸟巢演唱会顺序排列的可选名称；支持导入自定义列表、恢复默认和在光标处插入名称。
- 一键复制记录；按名称导出片段视频，可同时提取无损音频。显示导出视频总大小与原视频大小。
- 配置和文本记录在本机保存；更新检查自动重试、切换下载源，下载支持断线续传及 SHA-512 校验。
- 播放、分析和切割读取源文件时允许删除共享；视频可在资源管理器中删除，后续相关操作提示文件不存在，保留文本记录。

## 安装与开始使用

支持 **Windows 10 / 11 x64**，仅发布 NSIS 安装包 `Cut-Player-<版本>-x64-Setup.exe`。运行安装包后，从新建的桌面或开始菜单快捷方式启动。旧便携版已停止发布，请手动安装并使用新的快捷方式。

内置 Electron、FFmpeg 和 FFprobe，无需另装浏览器或命令行工具。播放本地文件不需要联网。播放器支持 Chromium 可解码的 H.264/AAC MP4、兼容的 WebM 等；MKV、MOV 等是否可播放取决于实际编码。安装包未进行代码签名。

1. 点击「打开视频」、拖入视频，或在 Windows「打开方式」中选择 Cut Player。
2. 用进度条、波形或快捷键定位，点击「＋ 记录当前时间」或按 `Ctrl+Alt+V` 添加断点。
3. 编辑片段名称，需要时点击可选名称按钮在光标处插入内容。
4. 点击「复制」带走完整记录，或点击「切割」选择输出目录。

右侧已有非空记录时，打开新视频会先确认；取消后保留原视频和记录。文本框可直接点击编辑。

## 默认快捷键

快捷键只在应用窗口内生效，均可在「快捷键与倍速」修改。

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 播放 / 暂停 | 空格 | 松开时切换，长按不反复切换 |
| 记录当前时间 | Ctrl+Alt+V | 长按不重复记录 |
| 复制全部记录 | Ctrl+Alt+C | 长按不重复复制 |
| 快退 / 快进 | ← / → | 默认每次 1 秒，长按连续；精细模式逐帧 |
| 音量 | ↑ / ↓ | 每次 5 个百分点 |
| 倍速 | 1 / 2 / 3 / 4 | 1× / 2× / 4× / 16× |

编辑文本时方向键、数字和空格保留输入功能，记录与复制组合键仍可用。倍速可设为 0.25—16，快进 / 快退界面步长可设为 0.1—600 秒。四档倍速、音量步长和快捷键配置均持久保存。

## 记录格式与导出

```text
breakpoints:00:10,01:23
names:video_20260926_202424x,video_20260926_202434x,video_20260926_202547x
```

断点为相对视频开始位置的累积分钟 / 秒，精细模式使用 `MM:SS.mmm`。名称数量必须比断点多一个，断点必须严格递增、大于零且小于视频时长。首次打开没有断点，只生成第一段名称；没有断点时导出整段。

片段顺序为：0 → 第一个断点、相邻断点之间、最后断点 → 视频末尾。输出直接写入所选目录；同名文件会询问是否覆盖，输出不能覆盖源视频。视频保留原容器并复制视频及音轨；勾选「同时导出无损音频」时，提取每段的第一条音轨，AAC 为 `.aac`，其他编码为 `.mka`。导出视频大小总和不含独立音频文件。

详细的命名规则、删除合并行为、初始化与名称列表用法见 [完整使用指南](docs/USER_GUIDE.md)。

## 更新与数据

从「帮助 → 检查版本更新」手动发起检查。下载完成后自动安装并重启；正在切割时等待切割结束。连接失败会轮换 GitHub Releases 与 Pages 备用源；下载失败保留已下载部分，在服务器支持时续传。也可通过浏览器下载 Setup.exe 覆盖安装。

`config.json` 保存快捷键、倍速、步长、音频选项、精细模式和可选名称列表；文本记录存于本机应用的 localStorage。Windows 数据目录通常为 `%APPDATA%/cut-player/`，升级沿用该目录。记录会暂存，但重置、初始化或确认打开新视频会改写记录，重要内容请先复制保存。

排查编码、更新网络、缺失源文件及记录格式问题，见 [故障排查](docs/TROUBLESHOOTING.md)。

## 开发与发布

Node.js 22，Windows x64 构建。需要安装依赖以及匹配的 FFprobe；完整步骤见 [开发与维护](docs/DEVELOPING.md)。

```sh
npm ci
npm test
npm start
npm run dist
```

现有 Windows Release 工作流执行单元测试、源码桌面测试、打包后测试、实际 NSIS 安装测试及性能比较，并发布对应版本的安装包与更新元数据。介绍页使用现有 Pages 工作流部署，文档更新无需重新发布应用版本。

当前 v1.5.11 已通过 23 项单元测试，以及源码、解包程序、实际安装程序的 Windows 桌面回归验证。新增代码后以对应 CI 运行结果为准。

## 实现与许可证

应用围绕 HTMLVideoElement 独立实现；曾评估 [tiny-player](https://github.com/wangrongding/tiny-player)，未复制其源码或发布其包。播放兼容性取决于 Chromium，内置 FFmpeg 用于分析和导出，不提供通用软件解码播放。

应用代码采用 MIT；FFmpeg 及相关第三方信息见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和安装包内声明。历史发布说明保留在 [release-notes/](release-notes/)。
