# Cut Player 使用指南

对应当前发布版本 **v1.5.12**。[在线介绍](https://shandianchengzi.github.io/cut-player/) · [README](../README.md) · [故障排查](TROUBLESHOOTING.md)

## 1. 安装与打开视频

下载最新版 `Setup.exe`，运行安装程序并选择安装目录。安装后从桌面或开始菜单快捷方式启动。旧便携 exe 不会自动变成安装版，请改用新的快捷方式；不要删除原 AppData 数据目录。

打开方式有三种：

- 点击「打开视频」选择文件。
- 将视频拖到窗口内。
- 在资源管理器右键视频 →「打开方式」→ 选择 Cut Player 的已安装 exe。应用会读取传入路径；已有窗口时在原窗口接收文件，不再新开窗口。

设置系统默认打开方式需通过 Windows 的「打开方式」或默认应用设置完成，安装器不会自动接管所有视频关联。程序支持中文、空格、`#` 等路径字符。

右侧只要已有非空记录，打开新视频都会显示确认框。「取消」保留当前视频和记录；「继续打开」为新视频重新生成初始记录。请先复制需要保留的旧记录。

## 2. 播放与定位

点击播放按钮或视频画面切换播放状态；默认空格在**松开**时切换，长按不会反复播放 / 暂停。进度条可拖动定位，悬停显示目标时间。音量滑块调节音量；「全屏」切换全屏，Esc 可退出。

| 操作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 播放 / 暂停 | 空格 | 自定义此键后同样在松开时触发 |
| 快退 / 快进 | ← / → | 默认 1 秒，长按连续移动，松开停止 |
| 减小 / 增大音量 | ↓ / ↑ | 默认每次 5 个百分点 |
| 倍速档 1—4 | 1 / 2 / 3 / 4 | 默认 1× / 2× / 4× / 16× |
| 记录时间 | Ctrl+Alt+V | 长按只记录一次 |
| 复制全部记录 | Ctrl+Alt+C | 长按不重复复制 |

「快捷键与倍速」内点击按键框，再按所需组合键；设置四档倍速、快进 / 快退秒数和音量百分比后保存。快捷键不能重复。设置页的「恢复默认」先恢复表单，点击「保存」后才应用。

快捷键是窗口内按键，不是系统全局热键。在文本框或导入输入框编辑时，方向键、数字和空格正常输入；记录和复制组合键仍有效。点击复选框及标签会尽量保留原焦点，便于继续用键盘控制视频。

## 3. 波形与精细模式

载入视频后后台分析音量波形和视频帧时间轴，准备状态显示在波形上方。分析结果会缓存在本机；无音轨时波形可能不可用，但视频帧分析仍可完成。

- 点击波形定位。播放中点击后继续播放；暂停时点击后保持暂停。
- 鼠标滚轮向上放大、向下缩小显示时间范围。
- 勾选「精细切割（逐帧）」时会暂停视频，左右键改为沿视频帧时间逐帧移动，长按可连续逐帧。
- 精细模式中点击波形会对齐帧时间；帧时间未准备好时，需等待分析完成。
- 精细模式记录 `MM:SS.mmm` 断点，自动名称使用毫秒时间戳或毫秒相对后缀。已有自动生成的名称会转换，手工改过的名称保留。

**精细模式提高的是定位、记录精度。所有导出仍为 `-c copy` 原码流复制，受关键帧限制，不保证切点逐帧精确。**取消勾选不会自动把已有毫秒记录或名称转换回原格式。

## 4. 记录与自动命名

首次打开视频，生成：

```text
breakpoints:
names:video_20260926_202424x
```

定位到 10 秒、83 秒分别点击「＋ 记录当前时间」或按记录快捷键后：

```text
breakpoints:00:10,01:23
names:video_20260926_202424x,video_20260926_202434x,video_20260926_202547x
```

实际文本必须是两行，名称全部写在 `names:` 后，以英文逗号分隔；文本框的自动折行不会改变结构。名称数为断点数加一。断点是相对源视频开始的绝对播放位置，必须递增，不能重复、为零或超出视频时长。超过一小时用累积分钟，例如 `60:10`。

普通模式按秒向下取整。新增名称根据「原视频拍摄时间 + 当前播放位置」计算，不累加上一段的时间。可识别：

| 原文件名类型 | 普通模式 |
| --- | --- |
| `video_YYYYMMDD_HHMMSS` 等日期时间名称 | 替换时间部分，保留其他前后缀，结尾加 x |
| `DJI_YYYYMMDDHHMMSS_编号_D` | 归一化为 `DJI_YYYYMMDDHHMMSSx` |
| 13 位 Unix 毫秒、11 位 Unix 秒（可含前导零） | 按原单位更新数值并保留宽度，结尾加 x |
| 未识别出拍摄时间 | 原名称加相对时间后缀，结尾加 x |

普通模式中的日历文件名按写出的钟面时间计算，不做时区转换，跨日 / 月 / 年自动处理。精细模式把日历文件名视为 **UTC+8** 后换算成 Unix 毫秒，不能作为任意拍摄时区的自动识别器。未识别日期的名称使用相对毫秒后缀。

文本可直接编辑，手工修改既有名称不会被后续记录覆盖。「复制」或复制快捷键将整个文本框复制到剪贴板。文本会自动暂存本机，但不是每个视频独立保存的一套历史记录。

## 5. 可选名称与导入

默认按钮列表采用此前整理的周深北京鸟巢演唱会顺序，包含歌曲、串场、点歌和工作人员致谢。「北京限定曲」「点歌1」「点歌2」等是可编辑的占位名称，并非按视频或演出日期自动识别曲目。

将光标放到要命名的位置，再点击名称按钮，名称会**插入光标处**，不会自动替换已有名称，也不会删除选中的文字。可先手工删除不需要的文字，再插入曲名。

「导入名称」操作：

1. 粘贴名称列表，或选择 UTF-8 的 `.txt` / `.csv` 文本文件（最多 200KB）。
2. 选择「空格 / 换行」「逗号」或自定义分隔符。
3. 点击「导入并替换列表」，替换的是可选按钮列表，不是右侧记录。
4. 若曲名含空格，例如 `Try Everything`，使用逗号或自定义分隔符，避免被空格拆开。
5. 导入面板右下角「恢复默认」立即恢复并保存内置列表，关闭面板；不会重写右侧记录。

重复名称会去重；最多 2000 个名称，名称不能包含逗号或换行。按逗号导入只是按分隔符拆分，不是带引号转义的完整 CSV 解析器。已有自定义列表在升级时保留。

## 6. 删除与初始化记录

文本框上方「删除」打开可滚动的片段选择列表，每项显示名称和时间范围。选择后点击「删除所选片段」，同步删除该名称与对应断点，保持两行数量关系。

- 删除第一段时，该时间范围并入后一段。
- 删除其他段时，该时间范围并入前一段。
- 仅剩一段时不能继续删除，请使用「初始化」。
- 删除的是记录项，不是裁掉这段视频，也不会删除磁盘文件。

例如：

```text
breakpoints:00:10,00:20
names:A,B,C
```

删除 B 后变为：

```text
breakpoints:00:20
names:A,C
```

此时 A 覆盖 0—20 秒，C 覆盖 20 秒—结尾，不会跳过原 B 的内容。

「初始化」确认后恢复当前视频的初始两行记录，清空全部已填断点和名称；精细模式保留精细名称格式。它用于格式损坏时重新开始，**不会恢复此前某次编辑的完整内容**。取消不修改记录；需要保留的文本请先复制。

## 7. 无损导出

点击「切割」，选择输出文件夹。程序直接写入该目录，不另建片段子文件夹。按 names 依次导出所有时间范围；没有断点时导出整段。

- 视频保留原容器，复制视频和音轨，使用 `-c copy`，不重新编码。
- 「同时导出无损音频」默认勾选，可关闭；开启时提取每段第一条音轨，AAC 输出 `.aac`，其他编码输出 `.mka`。无音轨则跳过并提示。
- 状态显示当前片段进度、已导出视频总大小及原视频大小；独立音频不计入视频总大小。总大小差异不是压缩率承诺。
- names 中名称须符合 Windows 文件命名规则，不能重复、包含路径或保留设备名。同名输出会先询问是否覆盖；禁止覆盖源视频。
- 导出前自动清理两行末尾多余逗号，行中间空项仍需修正。
- 失败时保留已经生成或未完成的文件，并显示输出目录；不会自动回滚删除它们。
- 导出期间不能切换视频，关闭窗口时会提示等待导出完成。

## 8. 删除磁盘源文件

v1.5.11 起允许在播放、分析或切割读取源视频期间，从资源管理器删除该视频。已缓冲的画面可能暂时可见；后续播放、定位、记录或导出时检查源路径，显示「源视频文件不存在（可能已被删除或移动），请重新打开视频」，已有文本保留。

若其他软件、权限或磁盘状态阻止删除，仍需处理对应原因。右侧「删除」按钮不承担磁盘文件删除操作。

## 9. 更新与备份

「帮助 → 检查版本更新」发起检查，下载完成后自动安装重启；切割中等待任务结束。检查时交替尝试 GitHub 与 Pages 更新源；下载断线时保留部分文件并尝试续传，服务器不支持 Range 时重新下载，安装前校验 SHA-512。

网络失败可选「稍后重试」「浏览器下载」「备用下载页」，或使用帮助菜单中的同名下载入口。浏览器下载最新 Setup.exe 后关闭播放器，覆盖安装，配置和记录沿用原本数据目录。

通常数据目录：`%APPDATA%/cut-player/`。其中 `config.json` 保存配置，localStorage 保存记录，`analysis-cache/` 保存分析缓存，`updates.log` 保存更新日志。关闭应用后备份整个数据目录；记录也建议单独复制成文本。
