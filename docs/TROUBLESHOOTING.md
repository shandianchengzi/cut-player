# Cut Player 故障排查

对应 **v1.5.11**。[使用指南](USER_GUIDE.md) · [下载最新版](https://github.com/shandianchengzi/cut-player/releases/latest) · [备用下载](https://shandianchengzi.github.io/cut-player/updates/)

## 更新失败：net::ERR_CONNECTION_CLOSED

这是更新连接被关闭的提示，不能据此判断安装包已损坏。当前版检查更新会交替尝试 GitHub 与 Pages，下载会重试并保留部分文件；支持 Range 的服务器可续传，不支持则重新下载。

1. 使用「帮助 → 检查版本更新」重试。应用使用 Electron 的系统代理会话；确认当前网络 / 系统代理可访问对应下载地址。
2. 仍失败时，在提示框或帮助菜单选择「浏览器下载最新版」或「备用下载页」。
3. 下载最新版 Setup.exe，关闭播放器后覆盖安装；从新的快捷方式启动，并在帮助菜单查看当前版本。
4. 持续失败时查看 `%APPDATA%/cut-player/updates.log`。日志超过约 1MB 时轮换为 `updates.log.previous`。

这些机制提高断线恢复能力，但不能保证被阻断的下载源始终可达。旧便携版更新已停用，需手动迁移到 Setup.exe；不要再次打开旧便携 exe 来判断是否更新成功。

## 视频打不开 / 只有声音 / 编码提示

播放器使用 Chromium 支持的解码能力，文件扩展名不是编码保证。优先使用 H.264/AAC MP4 或兼容 WebM；MKV、MOV、HEVC 等取决于实际编码和运行环境。内置 FFmpeg 用于分析与导出，不是通用播放软解码器。

如需转成兼容编码，请另行转换视频后打开；Cut Player 的「切割」为原码流复制，不会解决源编码不兼容。

## 新视频载入后文本框不能编辑

v1.5.4 起，打开确认改为页面内异步对话框，避免原生同步弹窗影响焦点。更新至当前版本，确认打开后直接点击文本框即可编辑，无需切换到其他应用。仍出现时，请记录复现方式（按钮、拖拽或打开方式）、是否有未关闭对话框、当前版本和文件类型。

## 左右键不能连续快进 / 快退

v1.5.8 起支持按键重复事件，长按连续移动，松开停止；普通模式按配置步长，精细模式逐帧。先点击视频或播放器按钮获得播放区域焦点，确认没有打开设置 / 导入等对话框。文本编辑时方向键保留移动光标功能。

精细模式须等帧时间轴准备好。修改过快捷键时，使用设置后的键；默认左右键不再承担该操作。播放 / 暂停键设计为松开触发，长按不反复切换。

## Windows「打开方式」未自动载入视频

v1.5.9 起处理启动参数和已有窗口的新文件。确认 Windows 关联的是当前安装目录中的 `Cut Player.exe`，而非旧便携 exe。将视频拖入或用「打开视频」确认文件可播放。已有非空记录时，新文件需在原窗口确认后才替换；点击取消则按设计保留原视频。

## 点击波形后意外暂停

v1.5.10 起，点击波形保持此前播放状态，普通与精细模式均适用。勾选精细模式以及精细模式的左右逐帧操作仍会暂停视频；这两种操作与点击波形不同。

## 删除时仍显示文件占用 / 源视频不存在

v1.5.11 改为支持 Windows 删除共享的流式读取。更新并从当前安装版启动后，可在资源管理器删除正在使用的源视频。若仍被阻止，检查旧版本进程、其他播放器 / 编辑器、目录权限等。

删除后再执行播放、定位、记录或导出，会提示源视频不存在，保留文本记录。需要继续使用该视频时，请恢复文件或重新打开有效文件。右侧「删除」只删除片段记录，不删除磁盘视频。

## 断点、名称或结构报错

记录必须为两行：`breakpoints:` 和 `names:`，值用英文逗号分隔。名称数量必须比断点多一个；断点严格递增、大于零且小于视频时长。普通断点用 `MM:SS`，毫秒断点用 `MM:SS.mmm`，超过一小时仍用累积分钟。

切割会清理行尾多余逗号，但不会忽略中间空项。名称还须符合 Windows 文件命名规则；不能重名、包含路径字符或保留设备名称。可手工修复，或先复制备份，再点击「初始化」恢复初始结构。初始化会清空当前断点和名称。

## 删除记录后片段仍被导出

删除记录会合并相邻时间范围，不会排除其中的影像。要理解合并结果，可查看 [删除示例](USER_GUIDE.md#6-删除与初始化记录)。当前工具按连续断点分段，没有跳过指定时间段的功能。

## 精细模式导出切点不完全一致

逐帧定位与毫秒记录不等于重新编码裁剪。当前全部导出使用 `-c copy`，切点受关键帧、时间戳和原容器限制。切割时不会自动改为重编码。

## 波形或帧时间分析失败

无音轨时波形不可用属于正常情况。分析时间取决于视频长度、文件读取和设备性能；精细模式需等待帧分析完成。确认源文件仍在原路径；升级后的重复载入会利用本机分析缓存。

若安装程序资源被安全软件移除，重新覆盖安装后检查；不要单独替换未知来源的 FFmpeg / FFprobe。开发模式须准备匹配的 FFprobe，见 [开发文档](DEVELOPING.md)。

## 切割失败或输出未完成

提示中保留 FFmpeg 错误及输出目录。确认源文件存在、输出目录可写、剩余空间充足、名称合法且不与源文件重名。已经生成和未完成的文件会保留，不会自动删除；重试遇到同名文件时先确认是否覆盖。

视频总大小不包含额外音频文件，不能用该数字代替目录实际占用空间。

## 配置或记录不见了

通常保存在 `%APPDATA%/cut-player/`：配置为 `config.json`，文本在本机 localStorage。当前设计不是按视频分别保存记录；确认打开新视频、初始化会替换文本。升级保留同一用户目录的数据，清理 AppData、换 Windows 用户或手动改数据目录可能改变读到的内容。

重要记录请先复制保存。排查时不要直接删除整个数据目录；关闭播放器后先备份，再进一步处理。
