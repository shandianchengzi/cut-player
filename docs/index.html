时间，随手记录

点击按钮或按 Ctrl+Alt+V，将当前播放时间追加到右侧文本。自动生成 breakpoints 与 names 两行；从 video、DJI 或 Unix 时间戳文件名提取拍摄时间，按播放位置同步生成片段名称。文本可自由编辑。

操作，按你的习惯

方向键控制音量与进度。1 / 2 / 3 / 4 默认切换 1× / 2× / 4× / 16×；全部快捷键、倍速及快进步长均可配置。

内容，一次带走

点击复制或按 Ctrl+Alt+C，复制整个文本框。设置与记录自动保存在本机，关掉再打开也能继续整理。

三步开始记录

  1. 从 Releases 下载 portable 免安装版，或运行 nsis 安装包。
  2. 打开本地视频，使用进度条或快捷键定位；按 Ctrl+Alt+V 记录。
  3. 按 Ctrl+Alt+C 复制全部内容，粘贴到你的切段清单或字幕工具。

快捷键在应用窗口内生效。支持常见 H.264/AAC MP4 和兼容的 WebM；其他文件能否播放取决于其音视频编码。内置 FFmpeg，无需额外安装。点击「按文本切视频」即可按 names 命名导出全部片段；默认同时导出音频，均采用 -c copy 原码流复制。AAC 输出 .aac，其他编码输出 .mka。无重编码切点受关键帧限制。快捷键和倍速等设置自动保存至本机 config.json。
