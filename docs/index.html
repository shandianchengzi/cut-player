01 / 打开视频

安装后，用你习惯的方式打开

下载 Setup.exe 安装包，运行安装后通过新建的桌面或开始菜单快捷方式启动。点击「打开视频」、把视频拖到窗口，或在 Windows 右键「打开方式」中选择已安装的 Cut Player.exe。

程序已运行时，新文件交给原窗口处理。右侧已有非空记录时，先确认是否重置；「取消」保留原视频和文本，「继续打开」生成新视频的初始记录。需要保留的内容请先复制。

旧便携版已停止发布。请手动安装 Setup.exe，并改用新的快捷方式，原本机数据目录会沿用。安装器不会自动接管所有视频的默认打开方式。

02 / 播放与定位

键盘、进度条、波形配合使用

点击播放按钮或视频画面控制播放，拖动进度条定位，悬停可查看目标时间。波形在后台分析后显示；点击波形定位时，播放中继续播放，暂停时保持暂停。滚轮向上放大、向下缩小波形。

精细切割（逐帧）实际改变什么？

勾选时会暂停视频；帧时间准备好后，左右键逐帧移动，长按可连续逐帧。波形定位对齐帧时间，断点使用 MM:SS.mmm，自动名称改用毫秒时间戳。手工改过的名称保留。取消勾选不会自动还原已有毫秒记录。

它提高定位与记录精度，导出仍为原码流复制，不能保证逐帧精确。精细模式的左右键会暂停；点击波形仍保持点击前的播放状态。

03 / 时间记录

两行文本，明确每段的起点和名称

打开视频后 breakpoints 为空，names 只有第一段名称。到达需要的切点，点击「＋ 记录当前时间」或按记录快捷键，同步追加一个断点和一个片段名称。

breakpoints:00:10,01:23
names:video_20260926_202424x,video_20260926_202434x,video_20260926_202547x

名称数必须比断点数多一个。实际文本是两行，值用英文逗号分隔；文本框视觉折行不影响结构。断点为相对视频开始的累积分钟 / 秒，严格递增、大于零且小于视频时长；超过一小时写为 60:10，精细模式可用 60:10.123。

名称从 video、DJI 或 Unix 时间戳文件名识别拍摄时间，用原视频时间加当前播放位置计算；未识别时间则加相对位置后缀。普通模式按秒向下取整。可直接编辑和复制，文本自动暂存在本机。

自动命名与时区细节

日期时间文件名在普通模式按原钟面时间计算，不做时区转换；DJI 名称归一化为 DJI_YYYYMMDDHHMMSSx。支持 13 位 Unix 毫秒和 11 位 Unix 秒（可含前导零）。精细模式将日历文件名按 UTC+8 换算为 Unix 毫秒，未识别时间的名称使用相对毫秒后缀。详见完整使用指南。

04 / 快速命名

默认演唱会顺序，也能换成你的清单

可选名称内置此前整理的周深北京鸟巢演唱会顺序，共 45 项，包含歌曲、串场、点歌和工作人员致谢。「北京限定曲」「点歌1」「点歌2」是占位名称，不会自动识别视频曲目或演出日期。

先将光标放到文本框的目标位置，再点击名称按钮，名称插入光标处。它不会自动替换原名或选中文字，需要替换时先手工删掉旧文字。

  1. 点击「导入名称」，粘贴列表或选择 UTF-8 的 TXT / CSV 文本（最多 200KB）。
  2. 选择空格 / 换行、英文逗号或自定义分隔符。曲名含空格时，推荐用逗号或自定义分隔符。
  3. 点击「导入并替换列表」。这会替换可选按钮列表，不改写右侧记录；重复名称去重，最多 2000 项。
  4. 导入面板右下角「恢复默认」会立即恢复并保存默认列表，随后关闭面板。

名称不能含逗号或换行。CSV 文件按选定分隔符拆分，不支持完整 CSV 引号转义。已保存的自定义列表升级后保留。

05 / 调整与恢复

删除记录，或重新初始化结构

文本框上方「删除」打开可滚动的片段选择列表，选择后删除名称和对应断点。第一段的时间范围并入后一段，其余段并入前一段。仅剩一段时请使用初始化。此操作只删除记录项，不删除磁盘视频，也不跳过这段影像。

例如 breakpoints:00:10,00:20 / names:A,B,C，删除 B 后变成 breakpoints:00:20 / names:A,C；A 覆盖 0—20 秒。

「初始化」确认后清空已填断点与名称，恢复当前视频的初始 breakpoints / names 两行；精细模式使用精细名称。它可修复格式损坏，但不能恢复此前完整编辑内容。取消不改动，重要记录请先复制保存。

06 / 无损分段

选一个目录，按 names 导出全部片段

点击「切割」选择输出目录。视频直接写入该文件夹，依次导出 0 → 第一断点、相邻断点之间、最后断点 → 视频末尾；没有断点就导出整段。视频保留原容器，复制视频和音轨。

默认勾选「同时导出无损音频」，提取每段第一条音轨：AAC 输出 .aac，其他编码输出 .mka；无音轨跳过并提示。可取消勾选，仅导出视频。

状态显示片段进度、已导出视频总大小和原视频大小，视频总和不含独立音频。同名输出先询问覆盖，不能覆盖源视频；名称须符合 Windows 文件规则且不能重复。

全部导出使用 -c copy，不重新编码，切点受关键帧限制。导出期间需等待完成后切换视频或关闭窗口；失败时已生成或未完成的文件保留在提示目录。

07 / 更新与数据

断线可重试，也可手动覆盖安装

「帮助 → 检查版本更新」手动发起检查。GitHub 连接失败会重试并切换 Pages 备用源；下载保留部分文件，服务器支持时续传，不支持 Range 时重新完整下载。安装包通过 SHA-512 校验后自动安装重启；正在切割时等待结束。

仍然失败可在提示框或帮助菜单选择「浏览器下载最新版」或「备用下载页」。下载 Setup.exe 后关闭播放器并覆盖安装，配置和记录沿用本机数据目录。

通常目录为 %APPDATA%/cut-player/：config.json 保存配置、localStorage 保存文本、analysis-cache 保存分析缓存、updates.log 保存更新日志。关闭应用后可备份整个目录。记录不是逐视频历史档案，打开新视频、初始化或重置会改写它，请先复制需要保留的内容。

常见问题

视频正在使用，能从资源管理器删除吗？

v1.5.11 起支持删除正在播放、分析或切割读取的源视频。已缓冲画面可能暂时可见；随后播放、定位、记录或导出会提示「源视频文件不存在」，保留文本。其他软件、权限或磁盘问题仍可能阻止删除。右侧「删除」按钮只是删除记录项。

更新报 net::ERR_CONNECTION_CLOSED 怎么办？

这是连接被关闭的提示。先重试，再尝试浏览器或备用下载页；手动覆盖安装会保留原数据。检查系统网络 / 代理和 updates.log。当前重试与续传提高恢复能力，但不能保证被阻断的下载源可达。

支持所有视频格式吗？

支持 Chromium 可解码的 H.264/AAC MP4、兼容 WebM 等；MKV、MOV 等取决于实际编码。内置 FFmpeg 用于分析和导出，不提供通用播放软解码。极高倍速音频表现也取决于 Chromium。

新视频不能编辑、长按失效、打开方式没载入？

当前版已包含文本焦点（1.5.4）、长按定位（1.5.8）、Windows 打开方式（1.5.9）和波形播放状态（1.5.10）的修复。确认启动的是当前安装版，关闭旧便携版；文本编辑时方向键仍保留输入用途。具体排查见故障文档。
